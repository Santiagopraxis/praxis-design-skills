Horizontal milestone road, used for cronogramas in kickoff decks and status reports.

```jsx
<Timeline steps={[
  { label: 'Kick-off', date: '20 Ago', status: 'done' },
  { label: 'Desarrollo', date: '25 Ago', status: 'current' },
  { label: 'Certificación', date: '21 Sep', status: 'upcoming' },
  { label: 'Go Live', date: '28 Sep', status: 'upcoming' },
]} />
```
