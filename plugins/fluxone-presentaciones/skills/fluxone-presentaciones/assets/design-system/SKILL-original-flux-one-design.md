# Flux One Design Skill

Read `README.md` first — voice, 4-pillar palette, bi-country rules, Stroke & Glow diagram spec. Import `colors_and_type.css` for all tokens. Never exceed font-weight 600. Never fill backgrounds with anything but pure `#000` or `#fff`. Never mix Colombia/México terminology in one component. Glassmorphism is decorative accent only.

For document-type pieces (propuestas, decks, PDFs, reports — anything with running text), always use the fixed document type scale, never smaller: título 30px, subtítulo 14px, texto largo 12px (cap), texto largo denso 10px. Use tokens `--flx-doc-title`, `--flx-doc-subtitle`, `--flx-doc-body`, `--flx-doc-body-dense` from `colors_and_type.css` — never shrink below these even with a lot of content; add pages/columns instead.
