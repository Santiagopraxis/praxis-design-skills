# Narrativa por tipo de deck

## A · Presentación general / venta a empresas (≈ 14–19 diapositivas)
Portada (F1) → frase (F2: "El dinero ya se mueve en segundos. ¿Tu operación también?") → reto (F3) → qué es (F4) → cómo funciona (F5) → orquestación en la práctica (F6) → México vs Colombia (F7) → para quién (F8) → así se ve un cobro (F9) → por qué fluXOne (F10) → NexaPay / WhatsApp (D1, D2, opcionales) → confianza (F13) → cierre (F12).

## B · White label para bancos / fintechs (≈ 14)
Portada negra "Su marca, nuestra tecnología" → frase "Construir infraestructura financiera toma años. La suya ya está construida." → el reto (3 cosas: tecnología, rieles, seguridad) → la propuesta (su marca al frente / fluXOne por detrás, diagrama de capas) → lo que puede licenciar (Control Tower, core financiero, wallet, IA vía MCP, Open Treasury, orquestador WhatsApp) → demos Control Tower y checkout (D3, D4) → medios de pago por país (F16) → modelo de trabajo → confianza → cierre. Tono "usted".

## C · Rueda de prensa / evento (≈ 20)
Bienvenida en negro (pantalla de espera) → portada → pregunta de apertura → agenda en 3 actos → Acto 1 El contexto (F11 + línea de tiempo F14 + qué dice la ley) → Acto 2 El hallazgo (cifras F15, F2 con la frase para titulares) → Acto 3 La respuesta (F4, F5, F9, demos) → referencia internacional (Brasil/PIX) → preguntas → cierre. Con `data-notes` para el vocero en cada diapositiva.

## Reglas de guion
- Título = conclusión, con la palabra clave en el color del pilar que trata.
- Una idea por diapositiva; 3–4 elementos por grilla; cuerpo ≤ 35 palabras.
- Cada cifra con fuente en `.src` o bajo la cifra.
- Cierra siempre con el slogan y la URL del país (fluxone.com.co / .mx) o el siguiente paso concreto.
- Notas para el expositor: atributo `data-notes="…"` en la `<section>` (no se muestran en la diapositiva).
